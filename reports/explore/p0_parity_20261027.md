# P0 完成报告：parity、数据精度、可复现性与价值语义（2026-10-27）

> 口径：纯策略；本轮只改工程与诊断，不做强度声明、不重训 A2、不重开搜索。
> 背景与决策草案：`reports/explore/literature_review.md`；代码审计：`reports/explore/lit/f07_code_audit.md`。

## 0. 结论

A2 的根因已在代码与真实 replay 上闭环：**compact fp16 把 definition id 压成不可逆假 id**。
本轮 P0 做了四件事：

1. **parity harness**：同 `(deck, opponent, seed, step)` 对比 replay/store 特征与 live 引擎特征，
   definition 列按整数 id 比；旧 dvalin fp16 语料第一处即报 `TOKEN_DEFINITION_ID`，新 compact 语料 5/5 决策 PASS。
2. **无损 id**：新 compact payload 额外写 `token_definition_ids`/`option_definition_ids`（int）与
   `definition_indices`；store 构建时修复 definition 列；A2 id 训练在缺 id 的旧语料上**直接拒绝**。
3. **可复现性**：模型构造前 `manual_seed`；`--save-best`（默认 `val_ce`）；`#t>0` 用 per-policy
   `torch.Generator`；eval seed 不再双倍偏移；`neural:` 强制 `--contestant-deck`。
4. **价值语义**：identity 价值头不再被当概率截断；acting-player 视角转成 player-0；dice “采样”从
   确定性轮转改为 i.i.d.；搜索的 frontier 不再把负值全压成 0。

命令：

```bash
python -m scripts.parity_store_live \
  --replay-dir data/replays/dfbc_dvalin_bonk_c80 \
  --deck dvalin_bonk --opponent natlan_battleship --seed 0 \
  --limit 2 --checkpoint data/checkpoints/a2/A0i.pt
```

| 计数 | 值 |
|---|---:|
| `TOKEN_DEFINITION_ID` | 10 |

示例：live `token id=330005` → store `330078`；live `option id=215071` → store `215039`。
这正是 `reports/explore/lit/f07_code_audit.md` 预测的 fp16 多对一映射，不是列错位。

### 1.4 A2 路径实测（完整干净语料，1 epoch 冒烟）

用四套干净语料建 store（1,600 局 / 85,573 决策，`definition_ids_present=85,573`），
跑 1 epoch `--id-buckets 1024 --id-emb-dim 32 --train-limit 10000 --val-limit 3000`：

- 正常训练、`--save-best` 生成 best checkpoint；
- report `n_definition_ids=85,573 / n_events=85,573`；
- checkpoint `definition_indices=[42,30]`，`load_cvpn_model` 可加载。

这说明 A2 重做的数据/训练/保存链路已通；剩下只是 A800 上的 150 epoch 全量训练与 dgeo/dvalin 认证。

### 1.5 A2 guard

旧 store（`definition_ids_present=0`）跑 `--id-buckets 8` 直接退出：

```
--id-buckets=8 needs lossless definition ids, but only 0/3150 samples carry them
(legacy fp16 corpus). Re-collect ...
```

新 store（51/51）可以正常训练 id 分支并保存 `definition_indices`。

## 2. 代码改动

| 文件 | 改动 |
|---|---|
| `train/data.py` | compact payload 写 exact int definition ids + `definition_indices`；`observation_from_payload`/`repair_observation_payload` 修复 definition 列；`sample_to_payload` 透传开关 |
| `scripts/datafirst_bc_store.py` | 读取时 repair；store meta 记录 `encoder_config`/`definition_indices`/`definition_ids_present` |
| `scripts/datafirst_bc_train.py` | 模型构造前 seed；store encoder/config/dim 校验；id 训练缺 id 直接拒绝；`--save-best`/`--select-metric`/`--best-out`；缺失 id 参数默认 zero-init |
| `scripts/train_bc_scale.py` | 同样 seed/`--save-best`；`train()` 保存 best 后恢复 last |
| `train/model.py` | checkpoint 保存 resolved `definition_indices`；加载时校验，错列直接报错 |
| `agents/neural.py` / `envs/policy.py` | `NeuralPolicy` 接收 seed，`torch.Generator` 采样；`build_policy` 透传 |
| `scripts/eval_protocol.py` | `_protocol_seeds(n)` 修双倍偏移；`match_seed` 落盘；`neural:` 强制 `--contestant-deck`；示例补 deck |
| `envs/parity.py` | `ParityRecorder` / `compare_observations` / `player_view_digest` |
| `scripts/parity_store_live.py` | replay vs live 的三层对比 + 可选 checkpoint logits |
| `envs/cfr_probe.py` / `train/resolver.py` | `value_probability()`；identity→概率；acting→player-0 |
| `reps/belief.py` | hidden dice 改为 i.i.d. 采样（仍由 public particle index 决定） |
| `scripts/p0_clean_corpus.sh` | 4-deck × 20 对手 × 20 seeds 干净语料 + store 一键续跑 |
| `scripts/p0_a2_rerun.sh` | A800 上 A0/A0i 重训 + 回流认证命令（A2 重做） |

新增测试：`tests/test_feature_parity.py`、`tests/test_eval_seed.py`、
`tests/test_neural_policy_seed.py`、`tests/test_belief_dice.py`、`tests/test_cfr_probe_value.py`。
