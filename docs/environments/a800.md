# a800 — 机会算力窗口（A800 80G）

## 事实

| 项 | 值 |
|---|---|
| 路径 | `/root/blockdata/genshin-GITCG`（以窗口实际为准；不要再写 `~/genshin-GITCG`） |
| GPU | A800-SXM4-80GB ×1 |
| CPU | **宿主 `nproc=128`，容器 cgroup `cpu.max` ≈10 核**；排产按 10 核算 |
| 存储 | `/root/blockdata` ~37G；`/` 30G；`/dev/shm` 50G 易失；`/public` 只读 |
| Python | `/root/blockdata/conda/gitcg/bin/python`；torch 2.7.0+cu126（以窗口实测为准） |
| 角色 | **只做 GPU 训练/推理**；采集/评测留本机/WSL（D21） |

## 数据流

1. 本机 `train.collect` 采集 compact（带 exact definition id）。
2. `rsync`/`scp` 传入 A800 的 `data/replays/`。
3. `train.pipeline` / `datafirst_bc_train` / `p0_a2_rerun.sh` GPU 训练。
4. checkpoint 回流本机 → `scripts/eval_protocol` 认证。

## 吞吐（实测）

- batch 512 训练 ~276k 样本/s；推理 ~201k 样本/s（窗口/模型相关）。
- 数据体积：jsonl ~1.64 MB/局；compact ~0.65 MB/局。
- 37G 存储：传入前先算体积；只传需要的 replay/checkpoint。

## 并发/坑

- `nproc` 显示 128 是宿主；实际只有 ~10 核，DataLoader worker 不要开满。
- 不要在窗口跑 `eval_protocol` 或大规模采集。
- 训练用 `--precollate`；checkpoint/日志回传后再做本地认证。
- 长任务一键零看管；先跑 1 epoch 冒烟确认数据/路径。
